# Hiperligações e Atributos

## Links Externos

A tag `a` com o atributo `href` cria ligações para recursos externos.
O atributo `target` define o local de abertura da página.
O valor `blank` abre a ligação numa nova aba.
O valor `self` abre na mesma aba.
O valor `parent` abre o conteúdo no frame pai.
O valor `top` abre o documento na janela principal.

O atributo `rel` especifica a relação entre páginas.
O valor `external` indica um destino externo.
O valor `nofollow` instrui motores de busca a ignorarem o link.
O valor `next` aponta para a página seguinte.
O valor `prev` aponta para a página anterior.
O valor `author` direciona para o criador.
Os valores `noopener` e `noreferrer` reforçam a segurança.

## Links para Download

A utilização do atributo `download` com `type` `application/pdf` permite transferir ficheiros diretamente.

## Links Internos e Navegação

As páginas conectam-se através de caminhos relativos ou subpastas.
Para entrar numa subpasta usa-se o nome da pasta seguido de barra e do ficheiro, como `noticias/page3.html`.
Para retroceder pastas e subir na hierarquia de diretórios utilizam-se dois pontos e barra, permitindo aceder a ficheiros na pasta anterior.
