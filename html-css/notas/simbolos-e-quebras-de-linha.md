# Notas sobre Parágrafos e Carateres em HTML

## Parágrafos e Espaços

* `<p>`: Define um parágrafo. O motor do navegador ignora quebras de linha e espaços múltiplos escritos no código fonte.

## Quebras de Linha e Linhas Horizontais

* `<br>`: Insere uma quebra de linha simples no texto. O uso repetido desta tag para criar espaçamentos verticais constitui uma má prática de estruturação.
* `<hr>`: Insere uma linha horizontal de separação visual entre conteúdos.

## Símbolos Especiais (Entidades)

* `&reg;`: Símbolo de marca registada.
* `&copy;`: Símbolo de direitos de autor.
* `&trade;`: Símbolo de marca comercial.
* `&euro;`: Símbolo da moeda euro.

## Emojis (Códigos Unicode)

* `&#x...;`: Os códigos Unicode para inserir emojis exigem obrigatoriamente a letra x em minúscula a seguir ao cardinal.
* `&#x1F920;`: Emoji de cowboy.
* `&#x26FA;`: Emoji de tenda.
