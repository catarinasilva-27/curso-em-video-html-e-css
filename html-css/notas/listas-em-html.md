# Listas em HTML

## Listas Ordenadas (`<ol>`)

* Servem para apresentar itens numa sequência lógica ou numérica.
* O atributo `type` define o estilo dos marcadores (`1`, `A`, `a`, `I`, `i`).
* O atributo `start` define o número inicial da contagem.

## Listas Não Ordenadas (`<ul>`)

* Servem para agrupar itens sem uma ordem específica.
* O atributo `type` aceita valores como `disc`, `circle` e `square`.

## Listas de Definição (`<dl>`)

* Agrupam pares de termos e respetivas descrições.
* `<dt>` define o termo a definir.
* `<dd>` define a descrição ou definição do termo.

## Listas Mistas

* É permitido aninhar diferentes tipos de listas umas dentro das outras dentro dos elementos `<li>`.
