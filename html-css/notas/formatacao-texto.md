# Tags de Formatação em HTML

## Negrito e Itálico

* `<b>`: Negrito visual, semântica ausente.
* `<strong>`: Negrito com importância semântica.
* `<i>`: Itálico visual, semântica ausente.
* `<em>`: Itálico com ênfase semântica.

## Destaques e Tamanhos

* `<mark>`: Texto marcado ou destacado.
* `<big>`: Texto com tamanho aumentado.
* `<small>`: Texto com tamanho reduzido.

## Alterações de Texto

* `<del>`: Texto excluído ou riscado.
* `<ins>`: Texto inserido ou sublinhado.
* `<sub>`: Texto subscrito.
* `<sup>`: Texto sobrescrito.

## Código e Blocos de Código

* `<code>`: Linha de código informático com fonte monoespacial.
* `<pre>`: Bloco de texto pré-formatado que preserva espaços e quebras de linha.

## Citações e Abreviações

* `<q>`: Citação curta em linha.
* `<blockquote>`: Bloco de citação longa.
* `<abbr>`: Abreviação com descrição acessível através do atributo title.
